## Alınacak fikirler
- **Üç girişli tek config (`electron.vite.config.ts` → `main` / `preload` / `renderer`).** Forge'un `vite-typescript` şablonunda aynı iş üç ayrı dosyada (`vite.main.config.ts`, `vite.preload.config.ts`, `vite.renderer.config.ts`) ve `forge.config.ts` içinde ayrıca listelenir. Quizloop'ta `electron.vite.config.ts` tek dosya olur; alias/plugin değişikliği tek yerde. Değerli: üç katman arasında ayar kayması (drift) fiziksel olarak imkânsızlaşır.
- **İki tsconfig + composite ayrımı.** Şablon `tsconfig.node.json` (main+preload, `types: ["electron-vite/node"]`) ile `tsconfig.web.json` (renderer, `jsx: react-jsx`, `paths: {"@renderer/*": ["src/renderer/src/*"]}`) kurar, `tsconfig.json` ikisini referanslar. Alias iki yerde tanımlanır: derleyici için `paths`, bundler için `renderer.resolve.alias`. Quizloop'ta `@renderer` + `@main` + paylaşılan `@shared` (tip ve IPC sözleşmesi) böyle bölünür. Değerli: renderer'a yanlışlıkla `node:fs` sızması tip düzeyinde yakalanır. `typecheck:node` ve `typecheck:web` ayrı script — CI'da ikisi de koşar.
- **`electron-vite dev -w`: renderer HMR + main/preload otomatik yeniden başlatma.** CLI'de `-w, --watch` "rebuilds when main process or preload script modules have changed on disk" olarak tanımlı; renderer tarafı normal Vite dev sunucusudur (main süreç `ELECTRON_RENDERER_URL` ile ona bağlanır). Quizloop'ta `npm run dev` = SQLite şeması/IPC değişince süreç yeniden doğar, React ekranı state kaybetmeden yenilenir. Değerli: soru kartı bileşenini denerken uygulamayı elle kapatıp açmazsın.
- **`build.externalizeDeps` varsayılan `true` (`src/config.ts`: `config.build?.externalizeDeps ?? true`).** `dependencies` altındaki paketler main/preload paketine gömülmez, `node_modules`'tan yüklenir. `better-sqlite3` için tek doğru davranış budur; şablon ayrıca `postinstall: electron-builder install-app-deps` ve `npmRebuild: false` kullanıyor — native modül Electron ABI'sine bir kez, kurulumda derlenir. Quizloop `better-sqlite3`'ü `dependencies`'e koyar, `devDependencies`'e değil.

## Kaçınılacaklar
- **electron-react-boilerplate'i temel almak.** Son etiketli sürümü 2022-05-15; webpack + `ts-node` + DLL ön-derleme (`build:dll`) üzerine kurulu, Vite yok. 17,5 MB'lık ve 190 açık issue'lu bir yapıyı Vite'a çevirmek sıfırdan kurmaktan pahalı. Okumaya değer tek yeri `.erb/scripts/check-native-dep.js` fikri (native bağımlılık yanlış yere kurulduysa kurulumu durdur) — deseni al, depoyu alma.
- **Forge + plugin-vite'ı `electron-builder` ile birlikte kullanmak.** Forge paketlemeyi kendi `maker`'larıyla yapar; `electron-builder`'ı yanına koymak iki paketleyici, iki config, iki imzalama yolu demektir. Ayrıca plugin-vite'ın React+TS şablonu yok (şablonlar: `vite`, `vite-typescript`) — React kurulumu zaten elle. Forge'un asıl kazancı `plugin-fuses` ve otomatik native modül açma; bunlar `electron-builder` tarafında `electronFuses` ve `asarUnpack` ile karşılanabiliyor.
- **`samuelmeuli/action-electron-builder`.** Arşivlenmiş (push 2024-05-26), son sürüm `v1.6.0` / 2020-06-18, 40 açık issue. CI matrisini bu action'a bağlama; `windows-latest` + `macos-latest` + `ubuntu-latest` üzerinde `npm ci` → `npm run build` → `electron-builder --publish always` üç satırla yazılır, `GH_TOKEN` yeter.
- **macOS'ta imzasız çıktının ne olduğunu belirsiz bırakmak.** electron-builder belgesi: imza kimliği yoksa imzalama tümüyle atlanır, **ad-hoc imza otomatik atılmaz**; ad-hoc istiyorsan `mac.sign.identity: "-"` demen gerekir. İmzasız/notarize edilmemiş `.dmg` indirildiğinde Gatekeeper karantinası "bozuk, açılamıyor" hatası verir; kullanıcı sağ tık → Aç ya da `xattr -dr com.apple.quarantine` yapmak zorunda kalır. Ayrıca ad-hoc + varsayılan `hardenedRuntime: true` birleşimi bilinen çökme kaynağı (electron-builder #9529). Quizloop kararı: sertifika alınana kadar `CSC_IDENTITY_AUTO_DISCOVERY=false` ile bilinçli imzasız derle, README'ye ilk açılış talimatını yaz, macOS artefaktını "unsigned" diye etiketle. Apple Developer Program yıllık ücreti (~99 USD) resmî fiyat sayfasından doğrulanmadı.
- **`v6.0.0-beta.1`'i kullanmak.** GitHub API'de `prerelease=false` görünüyor ama etiket `beta` ve Vite 8'e (`fix(deps)!: update vite to v8`) geçiyor. Quizloop `electron-vite@^5` ile başlasın.

## Karar önerisi
1. `npm create @quick-start/electron@latest` → `react-ts` şablonu; `electron-vite@^5`, `electron` 39, React 19, `electron-builder@^26` hazır gelir.
2. Şablonun `electron-builder.yml`'ını Quizloop'a uyarla: `appId`, `productName`, `publish.provider: github`, `mac.notarize: false`; kamera/mikrofon `extendInfo` satırlarını sil.
3. Alias'ları üç katmana yay: `@renderer`, `@main`, `@shared` — her biri hem `resolve.alias` hem ilgili tsconfig `paths` içinde.
4. `better-sqlite3`'ü `dependencies`'e ekle, `postinstall: electron-builder install-app-deps` ve `npmRebuild: false` satırlarını olduğu gibi bırak.
5. CI: tek `.github/workflows/release.yml`, `on: push: tags: ['v*']`, matris `[ubuntu-latest, macos-latest, windows-latest]`, adım `npm ci` → `npm run build` → `npx electron-builder --publish always`; macOS işine `CSC_IDENTITY_AUTO_DISCOVERY: false`.
